# Waste2Value — Frontend

React + Vite client application for the **Waste2Value** Smart Waste Exchange Platform.

## Features
- **Circular Economy Dashboard:** Track recycled material weight, estimated value, active listings, and Green Score.
- **Waste Listings Management:** Search, filter by category, and create new waste listings.
- **Waste Passport:** View user impact metrics and verification status.

## Setup & Run
1. `cd frontend`
2. `npm install`
3. `npm run dev` (Opens at `http://localhost:5173`)
